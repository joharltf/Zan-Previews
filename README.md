# Zan — Preview Images

Public home for social-preview / announcement images used by Zan game release
pages. This repo contains **images only** — no APK, no source, no build scripts,
no game data.

Raw image URLs here are safe to paste into Discord, Telegram or other chat
embeds.

## Add a new game

1. Create a folder named after the game.
2. Drop a 1280×640 PNG social preview in it.
3. Add a row to the table above.
